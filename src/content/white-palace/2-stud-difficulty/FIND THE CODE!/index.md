## Solution

*Note: Only use the solution if you are truly stuck or on the edge of giving up.*

??>

If you were to go to the conveyor belt inside the tycoon, you would see a hole at the end of it.
**Go into the hole** and walk until you reach the end of the tunnel.
If you use shift-lock and orient your camera in such a way that you can see behind the wall, you can find a link.
Upon inputting this link in a Web Browser, you get lead to "https://tycoongod.itch.io/tycoonproject".
Download the file in the Web-Page and open it. Wait for the game to load and Start Playing(Note:**You can move btw**).
After finding all the segments of the code(Write it from **Left-to-Right**), you can input it into the Code Terminal.

**Code: youfoundthecod3n1ce**
