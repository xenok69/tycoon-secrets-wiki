# Getting Started

Welcome to the **Tycoon Secrets non-official official wiki**, we do not own or control the content of the actual game.
The only [discord invite](https://discord.gg/RbeEtEgw9A) that we actually give out, is to the official 'Tycoon Secrets' discord server.

## Navigation

You can navigate through each page using the sidebar on your left, or jump directly to a specific page using the search bar in the bottom left corner.
Any help for a specific secret / page is welcome. We appreciate any feedback you might have to help improve the wiki.

## Frequently Asked Questions

**Q: Where can I find the answers to the secrets?**

A: We do not want to give out the answers directly as we want to keep the game alive and well.
What we do give out are hints to each secret, but never the answers themselves.

**Q: Is this website vibe-coded?**

A: Partially. The UI you see is directly from [shadcn](https://ui.shadcn.com/) but the whole structure is built with [Claude Code](https://claude.ai/).
All pages and texts you see on this website are **not** generated by AI.
We do not want to give out false hints or information, so all content is verified and written by human contributors.

**Q: Why are the hints here not complete?**

A: Do not worry, the hints are complete. Yet we do not want to give too obvious hints or information.
If you still search for more hints, you can always ask the official 'Tycoon Secrets' [discord](https://discord.gg/RbeEtEgw9A) server but don't expect to get the answers directly.
